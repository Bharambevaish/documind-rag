# Screenshots

Placeholder folder for the screenshots shown in the main README.
Run the app (`streamlit run app.py`), take these screenshots, and save them here
with exactly these file names. Then un-comment the image lines in the main README.

| File name | What to capture |
|---|---|
| `chat.png` | The Chat tab with a question answered and a citation like `[company_leave_policy.pdf, p.2]` |
| `sources.png` | The "📚 Sources" section expanded under an answer (file, page, score, snippet) |
| `not-found.png` | An out-of-docs question (e.g. "Who won the FIFA World Cup in 2022?") answered with "I couldn't find this…" |
| `sidebar.png` | The sidebar: upload box, document list with delete buttons, Top-K slider |
| `query-logs.png` | The Query Logs tab with the metrics row and the history table |
